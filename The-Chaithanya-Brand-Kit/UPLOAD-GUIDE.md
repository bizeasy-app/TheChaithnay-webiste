# The Chaithanya — Brand Kit

## Never-pixelated rule
- **SVG files are vector.** They stay sharp at any size: use them for print, Canva, websites, and for exporting new sizes later.
- **Social platforms don't accept SVG**, so every upload file is a PNG made at (or above) the platform's recommended size. Upload the PNG, never a screenshot.
- All text in the SVGs is converted to outlines, so they look right on any computer without installing the font.

## Logo masters (`01-logo-masters/`)
4 layouts × 4 colourways, each as SVG + 4000px transparent PNG.

- **Layouts:** horizontal (default) · stacked (square spaces) · monogram (avatars, icons) · wordmark (when the mark already appears nearby)
- **Colourways:** `color-on-light` · `color-on-dark` · `mono-black` · `mono-white`

## Colours
| Name | Hex | Use |
|---|---|---|
| Cloud | #F0EEE9 | Light background (60%) |
| Ink | #1A1714 | Text, the C, dark backgrounds (30%) |
| Saffron | #E8792B | The bindu and one highlight word (10%) |
| Indigo | #26305C | Support: thumbnail backgrounds |

Saffron is too light for small text on Cloud. Use it for the dot, shapes and big words only.

## Typeface
**Manrope** (free, Google Fonts). Titles: Bold 700. Body: Medium 500. Captions: ExtraBold 800.

## Don'ts
- Don't stretch, rotate or recolour the mark outside the 4 colourways.
- Don't move the bindu off the C's circle.
- Keep clear space of one bindu width around the logo.
- Smallest sizes: mark 16px, horizontal lockup 120px wide.
